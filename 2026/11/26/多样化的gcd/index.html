gcd 出现的题型分类

一、gcd 出现在哪里

gcd 的本质是 “两个数的最大公共度量” 。所以题目里一旦有“两个量之间来回折腾”的痕迹，就要往这想。

二、常见题型分类

知道我为什么写这个吗？你知道那种你自己明明复习了这个类型，结果写题压根没认出来他的无力感吗。

我知道写题要靠自己融会贯通，不能只是背题背模板。我先一步一步来吧

类型 1：纸面上直接写了倍数/约数

特征

最直白的一类，题干常出现：

“最大公约数”“最小公倍数”“约数”“整除”“能被……整除”

“把大块分成若干相等小块”“把两个尺寸切成一样长的小段”

“切割”“铺砖”“划分区间”

关键词：等分、切割、铺、分堆、整除。

例子

题目：一块长 36 米、宽 24 米的菜地，要切成同样大小的正方形，且正方形尽量大、正好切完不留余料，边长是多少？

解析：正方形边长必须同时整除 36 和 24，又要尽可能大，所以取两者的最大公约数。gcd(36,24)=12，边长为 12 米，共切成 (36/12)×(24/12)=3×2=6 块。


类型 2：周期性 / 同时发生 —— 多半是 lcm，背后是 gcd

特征

“每隔 x 天”“每隔 y 秒”“多久同时发生一次”——这是 最小公倍数 。而 lcm 的求法依赖 gcd：

lcm(a, b) = a / gcd(a, b) * b;

关键词：同时、同步、再次相遇、重合、周期、每隔……

例子

题目：甲每 4 天来图书馆一次，乙每 6 天来一次，今天两人同时来了，至少再过多少天再次同时来？

解析：再次同时 = 找能被 4 和 6 同时整除的最小天数，即 lcm(4,6)。lcm 用 gcd 求：lcm(a,b)=a/gcd(a,b)*b=4/2*6=12 天。特点：题目中出现两个周期、问“同时”的时刻，一定涉及 lcm/gcd。

类型 3：两个操作可以互相转换，问题问“能不能凑出来 / 到达某个状态”

特征

有两个“容器 / 集合 / 状态”，彼此之间可以 互相倒、互相转、互相扣

每一步只能“装满 / 倒空 / 转移”

问 能否达到某个目标 （能/不能，或最少几步）

关键词：倒水、装、倒、转移、混合、能否得到、是否可以达到。

一句话识别术： “两个东西能互相倒来倒去、问能不能凑出第三个值” → 立刻想 gcd。

例子

题目：

zwd和llw太无聊了，于是两个人在工位上打赌。zwd 从柜子里翻出一个容量为 a 的桶和一个容量为 b 的桶，两个桶上都没有刻度，旁边有一根可以无限接水的水龙头。

zwd 学姐扬言：只要有这两个桶，想要多少升水都能量出来。llw 觉得zwd在吹牛 —— 于是 zwd 随手报出一个数 c，让 llw 现场量给她看。

他只能做下面三种操作：

  1. 倒满：把某个桶装满水；
  2. 倒空：把某个桶里的水全部倒掉；
  3. 互相倒：把一个桶里的水倒进另一个桶，倒到「源桶空了」或者「目标桶满了」为止。

如果 llw 能用这两个桶量出 c 升，就说明 zwd 说得对；量不出来，llw 就能反将一军。请判断：这次到底是谁赢了？


输入

每个测试点都包含多组测试数据。第一行给定一个整数 T（1 ≤ T ≤ 10000），表示该测试点的测试数据组数。

对于每组测试数据： 输入三个整数 a、b、c，分别作为两个桶的容量和需要量出的水量。

输出

对于每组测试数据，输出一行：如果能够量出 c 升水，输出YES，否则输出NO。


解析：无论怎么折腾，两个桶的水量都是 g 的整数倍 （数学上叫 g 是该系统的最大不变量）。所以： 量出的水量 c 必须是 g = gcd(a, b) 的倍数。

类型 4：几何 / 网格计数 —— 要算“经过多少个点”

特征

比如从 (0,0) 到 (a,b) 的一条线段，穿过了多少个 整点 （坐标都是整数的点）？

答案是 gcd(a,b) + 1 （含端点），或 gcd(a,b)（不含起点）。

关键词：网格、格点、直线、线段、整点、有多少个整数点。

特点 ：题目是几何描述，但“整点”意味着取整数， 分子分母能同时约掉的数量 就是 gcd。看到二维坐标里有“整数网格”问题，先想 gcd。

例子

题目：从 (0,0) 到 (6,9) 的线段，一共经过多少个格点（横纵坐标都是整数的点，含两端）？

解析：线段上的格点数 = gcd(a,b)+1。沿线段每走 1/gcd 段就同时落在整数坐标上，共有 gcd 个等分，再加上起点。gcd(6,9)=3，所以共 3+1=4 个格点。

延伸：延网格走的最短路径问题

  • 若是 无障碍、只能上下左右走 ，从 (0,0) 到 (n,m) 的最短步数很简单： 答案 = n + m

       因为横向至少走 n 步、纵向至少走 m 步，每条都躲不掉。

  • 如果允许斜着走一步（八方向） ，则：答案 = max(n, m)

类型 5：分数化简 / 比例化简

特征

把 a/b 化成最简分数，分子分母同时除以 gcd(a,b)。

关键词：最简、约分、比例、化简、通分。

特点 ：比较直白，是 gcd 最原始的用途。

例子

题目：把分数 42/56 化成最简分数。

解析：最简分数就是分子分母同时除以它们的 gcd。gcd(42,56)=14，42/14=3，56/14=4，得到 3/4。

类型 6：环形 / 旋转 / 排列的“步长”

特征

比如 n 个位置的环，每次走 k 步，能走到哪些位置？会不会回到起点？

这取决于 gcd(n, k)： 如果 gcd(n,k)=1，能走遍所有位置；否则只能覆盖 gcd 个位置。

关键词：环、转圈、步长、循环、能否走遍、最远到达。

特点 ：“走 k 步”“数 k 个”“隔 k 个取”这类 离散步长 问题，本质上就是“最大公共度量”，用 gcd。

例子

题目：一个由 16 个位置围成的圆环，从 0 号位出发，每次顺时针走 12 步，能到达多少个不同的位置？

解析：能走到的位置个数由 gcd(n,k) 决定。gcd(16,12)=4，所以只能覆盖 4 个位置（依次为 0、12、8、4，之后回到起点）。如果 gcd(n,k)=1，则能走遍所有位置。

类型 7：染色 / 覆盖的边界问题

特征

1.题目里有个”周期”区间覆盖”的结构 ，让你问”能否全部染成某种状态”或”最少几种颜色”；

2. 元素之间有”距离”约束 ，这个距离往往和题给参数有关，而能否到达取决于 最大公约数 ；

3. 边界条件极其重要 ：0、负数、单点、n/k 整除关系、是否含端点。

关键词 : 染色、涂色、覆盖、标记

例子

题目：两点 i 和 j 能互相染色，当且仅当 |i - j| 是某个步长 d 的倍数。给定 n、d，问 整个区间在一条”步长为 d 的染色操作”下，能否全部染成同一种颜色？

解析：能”传递染色”当且仅当所有点落在 同一个”d 的模分类” 里，也就是：

若整个 0 ~ n-1 都能被一步长 d 连起来，需要 gcd(d, 1) = 1，其实要 d = 1 才能覆盖连续的所有点；

更常见形式： 问最少多少步 / 是否所有点都能被某个 d 的倍数覆盖 。

  • 核心套路 ：把”染色”转为”在模 d 下能否连通”。若 d 与 n 的 gcd 为 g，则能连通的是 n/g 个等价类， 必须 n/g = 1 才全部连通，即 d 与 n 互质且 d 较小 。
  • 边界条件

区间长度 = 1 ：不管 d 多少都是 YES；

d = 0 ：只能原地；

d ≥ n ：只能覆盖自己，n > 1 时 NO。

三、总结有关gcd的题目样式

题目里出现…… 备注
“最大公约数 / 整除 / 约分 / 最简” 直白
“同时 / 每隔 / 再次重合” 周期性
“两个东西互相倒 / 转 / 扣，能否凑出目标” 中期机试题的类型
“网格整点 / 线段穿过多少点” 几何计数
“环上走 k 步能否走遍” 步长
“分成同样大小的块 / 切割 / 铺满” 等分问题
