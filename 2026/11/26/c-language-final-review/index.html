C 语言期末高频易错知识点梳理

C 语言期末高频易错知识点梳理

适用范围：大一 C 语言期末考核
覆盖范围：基础语法 → 分支结构 → 循环结构 → 函数 → 数组 → 指针 → 字符串 → 动态内存 → 结构体/联合/枚举 → 常用数据结构
使用建议：先看每节的「易错点」表格，再对照代码示例，最后合上文档自己复述一遍。

一、数据类型与运算符

1.1 基本类型与长度（重点记 64 位环境）

类型 常见字节数 说明
char 1 本质是小整数，范围 -128~127（有符号）
long 4 或 8 Windows 下 4，Linux 64 位下 8，考试以题目环境为准
float 4 约 6~7 位有效数字
double 8 约 15~16 位有效数字
指针 4 或 8 由系统位数决定，与指向类型无关
  • 插播+enum

是 C 语言里用来定义“一组有名字的整数常量”的类型 。它的中文名叫 枚举类型 。

enum 让你把 几个相关的常量 打包，给它们起名字，生成一个新的类型。

核心：它本质上就是 int

它不是一个“新的、独立的”数据类型，而是给整数起的“有意义的名字” 。编译器大多把它当 int 处理。

1.2 运算符易错点

考点 正确理解 常见错误
整数除法 5 / 2 == 2 以为得 2.5；要得小数需 5.0 / 2
取模 % 只能用于整型；-7 % 3 == -1 对 float/double 用 %；以为结果恒为正
自增自减 i++ 先取值后加，++i 先加后取值 printf("%d %d", i++, i++) 属未定义行为，别这么写
短路求值 a && b：a 为假则不执行 b；a || b：a 为真则不执行 b 把有副作用的表达式放后面还指望一定执行
逗号表达式 值为最右边表达式的值 以为值是最后一个”运算结果”之外的
sizeof 是运算符，编译期求值，sizeof(int) 可不加括号写 sizeof i 把 sizeof 当函数；对指针求长度以为得到数组长度
位运算优先级 &、| 低于 == 和关系运算 if (a & 1 == 0) 实际是 a & (1 == 0)，必须写 (a & 1) == 0
优先级 ! > 算术 > 关系 > && > || > 赋值 > 逗号 不写括号导致的运算顺序错误

1.3 类型转换

  • 隐式转换：char/short 先提升为 int 再运算；int 与 double 混算结果为 double。
  • 有符号与无符号混用：-1 > 0u 为真（-1 被转成很大的无符号数）(u是 后缀 ，表示“这个常量是无符号的”)。
  • 强制转换：(int)3.9 == 3，是截断不是四舍五入。
  • char c = 300; 会溢出截断，结果是未定义/实现相关。

1.4 常量与字面量

写法 含义 易错
'A' 字符常量，本质是 int，值为 65 与 "A" 混淆
"A" 字符串常量，占 2 字节（'A' + '\0'） 以为占 1 字节
'0' 字符零，值为 48 与数值 0、'\0' 混淆
'\0' 空字符，值为 0，字符串结束标志 与字符 '0' 混淆
NULL 空指针，通常是 (void*)0 与 '\0'、0 混为一谈
0x41 十六进制 65
010 八进制 8，不是十进制 10 前导 0 被当成十进制
1e3 浮点数 1000.0 写成整数参与整除

二、输入输出（scanf / printf）

2.1 scanf 高频坑

考点 说明
必须传地址 scanf("%d", &a)，漏 & 是最常见错误
返回值 成功读入的项数；EOF 表示输入结束。while (scanf("%d", &n) != EOF) 是固定写法
%c 会读空白 前面的换行、空格会被当成字符读入
%s 遇空白即停 不能读含空格的字符串，读空格要用 fgets 或 %[^\n]
格式串不匹配 %d 却输入字母，会读取失败且残留在缓冲区
%f 输入 double 错误，double 必须用 %lf；输出 double 用 %f 即可
抑制赋值 %*d 表示读入但丢弃

2.2 printf 易错

  • %d、%f、%c、%s、%lf（输入）、%p（地址）、%%（输出百分号）。
  • %f 默认保留 6 位小数；%.2f 保留 2 位。
  • %5d 右对齐宽度 5，%-5d 左对齐。
  • 格式符与参数类型不匹配是未定义行为（如用 %d 输出 double）。

2.3 字符串输入

函数 特点 注意
scanf("%s", s) 遇空白停止，自动补 \0 不检查越界
gets(s) 可读空格 已从标准移除，禁止使用
fgets(s, n, stdin) 最多读 n-1 个字符，保留 \n 长度要减去 \0；末尾可能带换行需手动去掉
getchar() 读一个字符 常用来吃掉缓冲区残留的换行

strcspn(s, “\n”) ：返回 s 中第一个 ‘\n’ 之前的字符个数（即 ‘\n’ 的下标）；

s[…] = ‘\0’ ：把那个 ‘\n’ 换成结束符，实现“去掉换行”；

比 strlen 写法更稳 ，因为找不到 ‘\n’ 时它不会误伤，一行搞定。

三、分支结构

3.1 if 易错点

考点 说明
悬空 else else 与最近的、未配对的 if 配对，不是看缩进
条件真假 非 0 为真，0 为假；if (x = 0) 永远为假
分号陷阱 if (a > 0); 分号让 if 体变空语句
复合语句 if 后多条语句必须加 {}
浮点判断 不要用 == 判等

3.2 switch 易错点（重点）

考点 正确规则 常见错误
表达式类型 只能是整型（int、char、enum） 用 float、double、字符串
case 常量 必须是整型常量表达式 case n:（变量）、case 1+2: 可以
case 值唯一 同一个 switch 内不能重复 两个 case 1:
default 位置 可以放在任意位置，通常放最后 以为必须在最后
default 非必需 可以没有 以为必须有
break 没有 break 会穿透执行下一个 case 忘记 break 导致多输出
case 共用 case 1: case 2: 可共用一段逻辑 不理解为什么能共用
执行顺序 从匹配的 case 开始顺序往下执行，直到 break 或结束 以为每次只执行一个 case
switch 后括号 必须有 () 漏括号
case 内定义变量 C89 不允许；C99 需加块 {} 直接在 case 后定义变量

3.3 条件运算符

a > b ? a : b 是表达式，可嵌套、可作右值；?: 优先级低于关系运算，注意加括号。

四、循环结构

4.1 三种循环对比

循环 最少执行次数 特点
while 0 次 先判断后执行
do-while 至少 1 次 先执行后判断，末尾必须有分号
for 0 次 适合已知次数

4.2 for 易错点

  • 执行顺序：初始化 → 判断 → 循环体 → 迭代表达式 → 判断 → …
  • 三个表达式都可省略，但两个分号不能省：for (;;) 是死循环。
  • for (i = 0; i <= n; i++) 与 i < n 差一次，边界高频错。
  • 循环变量在 C99 可写 for (int i = 0; ...)，C89 不行。
  • 循环体内修改循环变量可能导致意外。
  • 浮点数当循环变量会累积误差，尽量用整数。

4.3 break 与 continue

语句 作用
break 跳出当前一层循环或 switch
continue 跳过本次剩余语句，进入下一次循环

关键区别：

  • continue 在 for 中会执行迭代表达式；在 while/do-while 中不会，如果更新语句在 continue 之后，就会死循环。
  • 嵌套循环里 break 只跳出内层，要跳出多层需用标志变量或 goto。

4.4 高频循环算法（几乎必考）

题型 关键点
求 1~n 的和/积 累加器初值 0，累乘器初值 1
判断素数 只需试除到 sqrt(n)，注意 n <= 1 不是素数
求最大公约数 辗转相除法 while (b) { t = a % b; a = b; b = t; }
求最小公倍数 a / gcd(a, b) * b，先除后乘防溢出
斐波那契 递归
水仙花数：指一个 3 位数，它各位数字的立方和等于它本身 拆位：n % 10个位、n / 10 % 10十位、n / 100百
数字逆序 rev = rev * 10 + n % 10;  n /= 10;                          1，rev * 10：把已有的 rev 左移一位 （给新位让出个位）   2. + n % 10：取出 n 的 个位 ，加到刚才腾出的个位上。   n /= 10; // 砍掉个位
冒泡排序 双重循环，外层 n-1 趟，内层 n-1-i 次，if (a[j] > a[j+1]) 交换
统计字符 while ((c = getchar()) != '\n') 分类计数

五、函数

5.1 声明与定义

考点 说明
函数声明（原型） 参数可只写类型：int add(int, int);
函数定义 参数必须写类型和名字
先声明后使用 定义在调用之后必须先声明
返回值 return 只能返回一个值；无返回值用 void
默认返回 非 void 函数没写 return 是未定义行为
main 标准写法 int main(void)，末尾 return 0;
函数不能嵌套定义 只能在函数外定义，函数内可以调用

5.2 参数传递（重点）

  • C 语言只有值传递：形参是实参的副本，修改形参不影响实参。
  • 想通过函数修改外部变量，必须传地址。

5.3 数组作参数（高频坑）

  • 数组名作实参，形参退化为指针，函数内 sizeof(arr) 得到的是指针大小（4 或 8），不是数组长度。
  • 所以数组长度必须额外传参：void f(int a[], int n)。
  • 二维数组作参数必须写列数：void f(int a[][4], int row)。

5.4 变量作用域、存储类别与内存分区

（1）存储类别：变量”能活多久、能被谁看见”

类别 作用域 生命周期 初值 所在内存区域
局部变量（含形参） 函数/块内 函数执行期间 随机值（不初始化） 栈
全局变量 整个文件（可 extern 跨文件） 整个程序 默认 0 全局/静态区
static 局部变量 函数/块内 整个程序 只初始化一次，默认 0 全局/静态区
static 全局变量 仅当前文件 整个程序 默认 0 全局/静态区
register 变量 函数/块内 函数执行期间 随机值 建议放寄存器，不能取地址

高频坑：static 局部变量只初始化一次，值跨调用保留，这是选择题常考点。
注意：static 不改变作用域，只改变生命周期（局部变量）或可见范围（全局变量被限制在本文件）。

（2）内存分区：变量”住在哪”

C 程序运行时，内存大致分为以下几个区域，考试常问”某某变量/字符串在哪个区”：

内存区域 存放内容 生命周期 是否自动初始化 特点与易错点
代码区（正文段） 编译后的机器指令、函数代码 整个程序 — 只读，不能修改
常量区（只读数据区） 字符串常量 "hello"、部分 const 数据 整个程序 — 修改字符串常量是未定义行为，如 char *s = "abc"; s[0] = 'x'; 错误
全局/静态区 .data 已初始化的全局变量、static 变量 整个程序 按给定初值 static 局部变量也在这里，所以值能跨调用保留
全局/静态区 .bss 未初始化的全局变量、static 变量 整个程序 自动清 0 这就是”全局变量默认 0”的原因
堆（heap） malloc / calloc / realloc 分配的内存 从申请到 free malloc 不初始化，calloc 清 0 泄漏、越界、悬空指针；空间大而慢
栈（stack） 局部变量、形参、函数返回地址 函数调用期间 不初始化，随机值 函数结束自动释放；空间小而快；递归过深会栈溢出

（3）一图流对照：每种变量住在哪里

（4）本小节高频易错清单

考点 结论
局部变量不初始化 随机值，直接用是经典错误
全局/static 变量不初始化 自动为 0
static 局部变量 只初始化一次，值保留到程序结束
函数返回局部变量/局部数组地址 错误：栈帧已销毁，返回的是悬空地址
char *s = "abc" 改内容 错误：常量在只读区；要可改用 char s[] = "abc"
形参和局部变量在哪 栈；所以函数之间不能直接互相访问局部变量
malloc 的内存在哪 堆；指针变量本身可能在栈
递归没有出口 栈溢出（stack overflow）
register 变量 不能 & 取地址，只是建议，编译器可忽略

5.5 递归

  • 必须有递归出口，否则栈溢出。
  • 递归调用在 return 之前是”递推”，之后是”回归”。
  • 斐波那契递归效率低（大量重复计算），考试可能问调用次数。
  • 阶乘、汉诺塔、全排列、二分查找、树的遍历是典型递归题。

5.6 其他易错

  • 函数名不能与变量名重名。
  • 函数可以递归但不能嵌套定义。
  • void 函数不能 return 值，但可以 return;。
  • 函数参数个数、类型必须与原型一致（C 中不匹配可能只是警告）。

六、数组

6.1 一维数组

考点 说明
下标 从 0 开始，到 n-1
越界 C 不检查越界，可能不报错但行为未定义
初始化 int a[5] = {1, 2}; 其余自动为 0
全零 int a[5] = {0};
指定位置 int a[5] = {[2] = 3};（C99）
长度 定义时 int a[] = {1,2,3}; 自动算 3
整体赋值 不能 a = b，只能逐个元素或 memcpy
数组名 是首元素地址，是常量，不能 a++、不能重新赋值
求长度 sizeof(a) / sizeof(a[0])，只在定义所在作用域有效

6.2 二维数组

  • int a[3][4]; 共 3 行 4 列，内存中按行连续存储。
  • a[i] 是第 i 行的一维数组名，a[i][j] 才是元素。
  • a 是首行地址，a + 1 跨一行（16 字节），a[0] + 1 跨一个元素（4 字节），这是高频选择题。
  • 初始化：int a[2][3] = {{1,2,3},{4,5,6}}; 或 int a[2][3] = {1,2,3,4,5,6};
  • 行数可省，列数不能省。

6.3 字符数组

七、指针

7.1 基础

概念 说明
&x 取地址
*p 解引用，取 p 指向的值
定义 int *p; 中 * 是指针声明的一部分，不是解引用
指针大小 固定 4 字节（32 位）或 8 字节（64 位），与类型无关
空指针 int *p = NULL;，解引用前要判空
野指针 未初始化或已释放的指针，危险
指针算术 p + 1 前进 sizeof(类型) 字节
指针相减 同数组内两指针相减得元素个数
指针相加 不允许，p1 + p2 无意义

7.2 高频易混：p++、*p++、(*p)++、++*p

表达式 含义
p++ 指针后移，返回原指针
*p++ 先取 *p，再 p 后移（等价 *(p++)）
(*p)++ p 指向的值加 1，指针不动
++*p 值先加 1，再取值（等价 ++(*p)）
*++p 指针先后移，再取新位置的值

7.3 指针与数组

  • a[i] 等价于 *(a + i)，也等价于 *(p + i)（p = a）。
  • &a[i] 等价于 a + i。
  • 数组名是指针常量，不能自增；指针变量可以。

7.4 指针数组 vs 数组指针（必考）

记忆法：看括号，先看 [] 是数组，先看 * 是指针。

7.5 函数指针

就是“一个指向函数的指针” 。

  • 特征：这个指针指向的不是普通的变量（如 int、char），而是内存中一段可执行的代码（即函数）的入口地址
  • 普通指针存的是数据的地址，而函数指针存的是代码的地址 。
  • 核心特征：把函数当成“数据”来传递
    • 赋值：因为函数名本身就代表函数的入口地址，所以可以直接把函数名赋值给函数指针 。
    • 调用：可以通过  (*指针名)(参数)  或简化的  指针名(参数)  来调用它指向的函数 。
  • 辨：指针函数 ( int *p(int, int) )：本质是函数。它是一个普通的函数，只不过它的返回值是一个指针 。

7.6 二级指针

  • int **pp; 指向「int* 的指针」。
  • 常用于：在函数内修改外部指针本身（如动态分配后带回）、二维动态数组、指针数组传参。

7.7 const 与指针（高频）

写法 含义
const int *p 指向的内容不能改，指针本身可改
int * const p 指针本身不能改，内容可改
const int * const p 都不能改

记忆法：const 在 * 左边修饰内容，在 * 右边修饰指针本身。

7.8 void *

  • 通用指针，可接收任意类型地址，可隐式转回。
  • 不能解引用、不能做指针算术，必须先转换类型。

7.9 指针易错清单

  • 未初始化就解引用（野指针）。
  • free 后继续使用（悬空指针）。
  • 函数返回局部数组的地址（函数结束即失效）。
  • 指针类型不匹配（int* 赋给 double*）。
  • 混淆 char *s = "abc" 与 char s[] = "abc"：前者指向只读常量区，不能改。

八、字符串

8.1 核心规则

  • 字符串以 '\0' 结尾，所有字符串函数都依赖它。
  • strlen 不含 '\0'；sizeof 包含 '\0'（对数组而言）。
  • char s[] = "hello"; → sizeof(s) == 6，strlen(s) == 5。
  • char *s = "hello"; → sizeof(s) 是指针大小 8，strlen(s) == 5。

8.2 常用字符串函数（<string.h>）

函数 功能 易错
strlen(s) 求长度（不含 \0） 返回 size_t 无符号，strlen(a) - strlen(b) 可能变成巨大正数
strcpy(d, s) 复制 不检查越界，目标必须够大
strncpy(d, s, n) 限长复制 可能不补 \0
strcat(d, s) 追加 目标必须够大
strcmp(a, b) 比较 返回 <0 / 0 / >0，不能用 == 比较字符串
strchr(s, c) 找字符 返回指针或 NULL
strstr(s, sub) 找子串 返回指针或 NULL
strncmp(a, b, n) 限长比较
memcpy / memset 内存复制/填充 memset 按字节填充，不能给 int 数组赋非 0 值

8.3 字符数组 vs 字符指针

对比 char s[] = "abc"; char *s = "abc";
存储 栈上数组，可修改 指向只读常量区，不可修改
sizeof 4（含 \0） 8（指针大小）
可赋值 可逐个改 s[0] s[0] = 'x' 是未定义行为
能否整体赋值 不能 可以改指向

8.4 字符串处理高频坑

  • 忘记给 '\0' 留位置。
  • 用 gets（不安全，已废弃）。
  • 手写 strlen 时忘记判 '\0'。
  • 中文字符占多个字节，按字节处理会拆坏。
  • strcmp 返回值用 == 0 判断相等，不要用 == 1。

九、动态内存分配

9.1 四个函数

函数 作用 是否初始化
malloc(size) 申请 size 字节 不初始化，内容随机
calloc(n, size) 申请 n 个 size 字节 初始化为 0
realloc(p, size) 调整已分配块大小 新区域不初始化
free(p) 释放 —

9.2 高频易错点

考点 说明
大小计算 必须 n * sizeof(int)，不能写 n 或 sizeof(int*)
判空 malloc 可能返回 NULL，要检查
类型转换 C 中 void* 可自动转，但建议强转
realloc 失败 返回 NULL，原内存仍有效；不能直接 p = realloc(p, ...)，会丢失原指针
重复 free 未定义行为
释放非堆内存 free 栈变量、free 常量区地址都错误
内存泄漏 申请后未释放，程序结束前一直占着
释放后使用 悬空指针，未定义行为
越界写 破坏堆结构，可能崩溃
malloc(0) 实现相关，可能返回 NULL 或可 free 的指针
free(NULL) 安全，什么都不做

十、结构体、联合体、枚举

10.1 结构体基础

考点 说明
定义末尾分号 漏写是编译错误
类型名 除非 typedef，否则必须写 struct Student
成员访问 变量用 .，指针用 ->
整体赋值 可以 s2 = s1，但不能 s1 == s2 比较
比较 需逐成员比较或 memcmp（有对齐填充风险，不推荐）
函数传参 默认值传递，大结构体应传指针 &s 或 const struct S *
自引用 链表结点必须用指针：struct Node *next;

10.2 typedef

10.3 内存对齐（sizeof 高频）

  • 结构体大小不一定等于各成员大小之和，会有填充字节。
  • 对齐规则：每个成员相对结构体起始地址的偏移是其对齐数的整数倍；结构体总大小是最大对齐数的整数倍。

调整成员顺序可减少填充，这是常考”如何优化结构体大小”。

10.4 联合体 union

  • 所有成员共用同一块内存，大小等于最大成员的大小（再按对齐补齐）。
  • 同一时刻只有一个成员有效。
  • 常用于判断大小端、节省内存。

10.5 枚举 enum

  • 枚举本质是整型，可赋整数值。
  • 默认从 0 开始递增，可手动指定。
  • 可以用于 switch。

10.6 结构体易错清单

  • 定义后漏分号。
  • -> 与 . 混用。
  • 结构体数组的遍历：p[i].name 或 (p + i)->name。
  • 把结构体当参数值传递导致大拷贝。
  • 嵌套结构体访问层级写错。
  • 自引用结构体写成 struct Node next;（无限大小，编译错误）。

十一、常用数据结构

11.1 栈

  • 入栈先 ++top 再存；出栈先取再 top--。
  • top 初始为 -1 表示空栈，这是最常见写法。
  • 栈的应用：括号匹配、表达式求值、进制转换、递归。

11.2 队列（循环队列）

  • 循环队列用 (rear + 1) % N == front 判满，牺牲一个空位区分空和满。
  • 队列应用：BFS、任务调度、缓冲区。

11.3 顺序表

  • 插入：先移动后面元素（从后往前），再放入。
  • 删除：先取出元素，再移动前面元素（从前往后）。
  • 插入/删除时间复杂度 O(n)，按下标访问 O(1)。

11.4 排序与查找

算法 时间复杂度 稳定性 关键点
冒泡排序 O(n²) 稳定 相邻交换，外层 n-1 趟
选择排序 O(n²) 不稳定 每趟选最小放前面
插入排序 O(n²) 稳定 像扑克牌插入
二分查找 O(log n) — 必须有序，mid = low + (high - low) / 2
